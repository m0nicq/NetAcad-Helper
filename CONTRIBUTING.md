# Contributing to Cisco Netacad Auto-Solver

Thank you for your interest in contributing to CISCO Netacad Auto-Solver! We welcome contributions from the open-source community to make this extension better, more accurate, and easier to use.

Here are some guidelines to help you get started:

## How to Contribute

### 1. Report Bugs & Request Features
If you find a bug or have an idea for a new feature, please [open an issue](https://github.com/sanaysarthak/cisco-netacad-autosolver/issues) first to discuss it.

### 2. Submit Pull Requests
If you want to contribute code:
1. **Fork** the repository on GitHub.
2. **Clone** your fork to your local machine:
   ```bash
   git clone https://github.com/YOUR_USERNAME/cisco-netacad-autosolver.git
   ```
3. **Create a branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   # or
   git checkout -b fix/bug-description
   ```
4. **Make your changes** and test them locally (see the setup/installation section in the [README.md](README.md)).
5. **Commit** your changes with clear, descriptive commit messages:
   ```bash
   git commit -m "Brief description of the changes"
   ```
6. **Push** your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request** (PR) against the `main` branch of the original repository.

---

## Code Guidelines
- Keep code clean, readable, and commented where necessary.
- Follow the manifest V3 standards for Chrome Extensions.
- Avoid committing or exposing personal Google Gemini API keys in the code. Always use the placeholder values.
